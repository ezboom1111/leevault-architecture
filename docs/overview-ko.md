# LeeVault: 대화를 다음 작업의 근거로 연결하기

LeeVault는 Claude·Codex와 일하면서 나온 결정·정정·결과를 보존하고,
다음 작업에서 원본과 함께 다시 활용하기 위한 개인 지식 시스템입니다.
이 저장소는 그 **아키텍처 공개본**입니다. 운영 소스 전체, 실제 대화,
개인 볼트, 업무 데이터와 지원서 자료는 포함하지 않습니다.

## 왜 만들었나

“예전 보고서처럼 만들어줘”라고 했는데 AI가 이전 HTML을 읽지 않고
그럴듯한 스타일을 새로 만드는 문제가 있었습니다. 대화가 저장됐다는
것만으로는 다음 결과물의 연속성을 보장하지 못했습니다.

그래서 저장 → 검색 → 원본 읽기 → 실제 사용 → 결과 검증을 나누고,
어느 연결에서 실패했는지를 측정하는 방향으로 발전시켰습니다.

## 역할 분담

- **LeeVault 자체 코드:** 출처·버전·기억·정정·검색·작업 기록 관리.
- **Claude·Codex:** 평소의 기획·개발·디자인·조사와 의미 판단.
- **교체 가능한 작업자:** 프로젝트 작업 요령 생성과 별도 검토.
  현재 Claude가 설정돼 있고, Hermes는 대안으로 실제 시험했습니다.
- **Graphify·코드 그래프:** 관계 탐색이 필요할 때 사용하는 보조 지도.
- **Obsidian:** 문서 열람과 탐색 화면. 기억 엔진 자체는 아닙니다.
- **통합 대시보드:** 프로젝트·업무·산출물·실행 상태를 관리하는 몸통.
  지식 조회 연결은 있지만, 작업 결과가 두뇌의 개선으로 되돌아가는
  전체 연결은 아직 완료하지 않았습니다.

## 자동화의 범위

설정된 로컬 대화에서는 훅으로 발화를 저장하고 관련 근거를 전달합니다.
AI가 개선 작업을 등록하면 별도 작업자가 생성·검토하고 파생 자료로
저장할 수 있습니다. 사용자에게 일일 태깅이나 승인 큐 관리를 요구하는
방식은 아닙니다. 그러나 유용한 원본과 개선 작업을 고르는 AI 판단은
필요하며, 모든 앱·파일을 연결만으로 자동 이해하는 것은 아닙니다.

여기서 개선은 **수정된 근거와 검증된 작업 요령을 다음 작업에 적용하는 것**입니다.
모델 가중치 학습, 전 분야의 무인 성능 향상, 서버 없는 24시간 실행을
뜻하지 않습니다.

## 검증과 공개 범위

[현재 상태](runtime-status.md)는 비공개 런타임의 제한된 시험 결과와
공개 저장소에서 재현할 수 있는 검사를 구분합니다.
[두뇌–몸통 연결 문서](brain-body-integration.md)는 이미 있는 연결과
앞으로 구현할 부분을 구분합니다. 지원·소개 자료로 인용할 때도 이
구분을 유지해야 합니다. 특정 기업의 공식 제품이나 인증을 주장하지 않습니다.

실제 데이터 대신 구조, 실패에서 얻은 교훈, 평가 기준, 공개 경계 검사
코드와 합성 테스트를 공개합니다. 공개 열람과 오픈소스 라이선스 부여는
다르며, 현재 저장소에는 별도 재사용 라이선스를 부여하지 않았습니다.
